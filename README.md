# MacOS Web Clone

A web-based interactive replica of the macOS desktop experience, built using modern web technologies. This project simulates the look and feel of macOS, complete with draggable windows, a dock, a top menu bar, and various mini-apps.

## 🚀 Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** React Icons

## ✨ Features

- **Draggable & Manageable Windows:** Open, close, minimize, and move app windows around the desktop.
- **Interactive Dock:** Launch applications directly from the macOS-style dock.
- **Top Menu Bar & Context Menus:** Native-feeling top bar and right-click context menus.
- **Custom Apps:** Includes various simulated apps like Finder, Calculator, Safari, Calendar, and a Developer profile.
- **Dynamic Wallpapers:** Change your desktop background through the Wallpapers app.
- **Boot Screen:** A realistic macOS startup sequence.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd macos-web
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser to view the desktop.

## 📜 Scripts

- `npm run dev`: Starts the local development server.
- `npm run build`: Bundles the app for production.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Runs ESLint to check for code quality issues.
